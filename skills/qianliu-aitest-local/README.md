# 千流灵测 - 本地 AI 自动化测试

基于千流灵测客户端 HTTP 服务，在本地解析测试用例（xlsx / json / markdown）并并发调度执行，支持实时进度监控、日志持久化和 Markdown 测试报告生成。

---

## 环境要求

- **千流灵测客户端**（必须）— [下载安装](http://chatgpt.sangfor.com/e2eplugin/update/main/install/prod_v2/install.exe)，启动后默认监听端口 `8123`
- **Node.js >= 22**（浏览器操作需要）— [下载安装](https://devops.sangfor.com/static/attachments/software/node-v22.14.0-x64.msi)，普通测试用例无需安装

---

## 快速开始

安装并启动千流灵测客户端后，在 Claude Code 中输入：

```
/qianliu-aitest-local
```

首次使用选择 **Demo 快速模式**，使用内置 Demo 用例一键验证客户端连通性，无需任何配置。

运行成功后，可参照以下资源准备自己的测试用例和测试知识库：

- **用例编写规范**：`assets/testcase-guide.md`
- **用例格式示例**：`assets/example/testcase.example.md`
- **测试知识库示例**：`assets/demo/knowledge-demo.yaml`

## 触发方式与能力一览

| 能力 | 说明 | 触发示例 |
|:---|:---|:---|
| 默认调度执行 | 健康检查后弹出模式选择，按选择执行 | `/qianliu-aitest-local 本地AI测试` |
| 自定义快速模式 | 传入用例文件路径，全自动执行 | `/qianliu-aitest-local 使用 /path/to/cases.md 执行测试` |
| 默认快速模式 | 复用历史配置直接执行（需有历史执行记录） | `/qianliu-aitest-local --reuse` |
| 指定任务调度 | 传入历史任务目录路径直接执行（需有历史执行记录） | `/qianliu-aitest-local 执行任务目录 .qianliu/.qianliu-aitest-local/local_tasks/task_xxx` |
| 生成测试报告 | 传入历史任务中的状态文件路径，生成 Markdown 报告（需有历史执行记录） | `/qianliu-aitest-local 生成测试报告 .qianliu/.qianliu-aitest-local/local_tasks/task_xxx/run_case_status.json` |
| 编写测试用例 | 根据需求生成 Markdown 格式测试用例文件 | `/qianliu-aitest-local 帮我写本地灵测测试用例` |

### 执行模式说明

触发默认调度后，可从以下模式中选择：

- **Demo 快速模式** — 使用内置 Demo 用例一键验证，无需任何配置
- **自定义快速模式** — 传入用例文件路径（+ 可选知识库/并发数），全自动执行
- **默认快速模式** — 复用上次的配置直接执行（需有历史执行记录）
- **引导配置模式** — 逐步向导，从头初始化所有配置

### 测试报告

任务执行完成后，报告自动生成在任务目录下：

```
{项目目录}/.qianliu/.qianliu-aitest-local/local_tasks/task_xxx/
├── test_report_{date}_{time}.md    ← Markdown 测试报告
├── run_case_status.json            ← 执行状态汇总
└── run_log_{timestamp}/            ← 逐用例执行日志
```

也可通过可视化面板查看：`http://localhost:{port}/dashboard/#ai-test`
